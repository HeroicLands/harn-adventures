Hârn Adventures is a collection module for [Foundry VTT](https://foundryvtt.com/).
It gathers fan-written works for the [HârnWorld](https://columbiagames.com/harnworld/)
setting, published on the fan site [Lythia.com](https://www.lythia.com/), and presents
them as ready-to-play adventures, each one importable on its own.

It is a module, not a game system: it installs into a world that is already running
one. The documents it ships carry no system data, so they import into a world running
any game system.

## Install

Paste this manifest URL into Foundry's **Install Module** dialog:

```text
https://github.com/HeroicLands/harn-adventures/releases/latest/download/module.json
```

The source, the release history and the issue tracker are on GitHub, at
[HeroicLands/harn-adventures](https://github.com/HeroicLands/harn-adventures).
